# Codex 장면 이미지 UI 확장 v0.1.9

실리태번 마법봉 메뉴에서 장면을 선택하고 이미지 프롬프트를 작성·번역·생성하는 확장입니다. 이미지 생성에는 함께 제공되는 Codex 장면 이미지 서버 플러그인이 필요합니다.

## 설치

ZIP을 풀어 `manifest.json`, `index.js`, `prompt.js`, `style.css`를 실리태번의 `public/scripts/extensions/third-party/codex-scene-image/`에 넣습니다. `manifest.json`이 그 폴더 바로 아래에 있어야 합니다. 브라우저를 새로고침하세요.

v0.1.3 이후의 서버 플러그인이 이미 설치되어 있다면 UI만 업데이트해도 됩니다. 처음 설치하는 경우에는 서버 ZIP의 설치 안내도 따라 주세요.

## 사용

1. 채팅에서 마법봉 메뉴의 **이미지 생성 (Codex)**을 열고 기준 메시지를 고릅니다.
2. **이미지 스타일**에서 **실사**, **반실사**, **2D** 중 하나를 선택합니다. 기본값은 실사이며 마지막 선택을 기억합니다. 프롬프트 작성 지시문에는 선택한 화풍과 인물의 개성을 살린 미화 지시가 들어갑니다.
3. **프롬프트 작성용 연결 프로필**에서 **현재 RP 모델** 또는 실리태번에 저장된 연결 프로필을 고른 뒤 **이미지 프롬프트 받기**를 누릅니다.
4. 영어 프롬프트를 직접 수정할 수 있습니다. 필요하면 **번역용 연결 프로필**을 따로 선택하고 **번역하기**를 누릅니다. 두 프로필 선택은 각각 저장됩니다.
5. **Codex 모델**을 선택하고 **이미지 생성**을 누릅니다. 생성에는 위쪽 영어 프롬프트가 사용됩니다. 완료되면 미리보기와 원본 열기 링크가 표시됩니다.

기준 메시지까지의 대화에서 실리태번의 World Info 설정으로 활성화되는 로어북 항목도 프롬프트 작성에 전달합니다. NPC의 이름이나 별칭을 키워드로 쓰는 항목은 해당 키워드가 검색 범위에 들어오면 반영됩니다. 작성용 모델은 선택한 장면에 실제로 등장하는 인물의 외형 정보를 사용합니다.

프롬프트 작성 모델은 장면의 한순간을 고르고, 그때 그 자리에 있는 인물을 첫 문단에서 화면에 배치합니다. 빈 장소, 한 사람, 두 사람, 단체 장면마다 인원과 공간에 맞춰 구도를 잡습니다.

스타일을 바꾼 뒤 **이미지 프롬프트 받기**를 누르면 새 스타일로 영어 프롬프트를 작성합니다. 직접 작성하거나 수정한 영어 프롬프트는 입력한 문구 그대로 사용됩니다.
